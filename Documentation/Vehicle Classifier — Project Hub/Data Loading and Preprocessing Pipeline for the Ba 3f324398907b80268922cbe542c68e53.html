1. Link to the Central Question

Can we build a reliable system that classifies vehicles from traffic-camera images, explains its failures, and recommends human review for uncertain predictions?

This stage supports the "reliable" and "reproducible" parts of the question. Every model in the project (baseline CNN, balanced-batch variants, ResNet18 transfer learning) receives its images through one documented, seeded, leakage-free pipeline. Differences between experiments then come from the factor under test, not from the input pipeline.

4. Design decisions

4.1 Manifest-based Dataset instead of ImageFolder

The train/validation split lives in the manifest (with group_id), not in folders. A custom ManifestDataset(df, transform) reads rows of the manifest, opens each image on demand, converts it to RGB (so grayscale or RGBA files cannot break the first convolution), applies the injected transform, and returns (image, label). Passing the transform from outside lets one class serve both the train (augmented) and validation (deterministic) sides.

4.2 One fixed class mapping

CLASS_NAMES is a fixed, sorted list; indices come from enumerate. load_manifest raises an error for any class outside the list, so a label can never silently become NaN, and the same mapping is reused for validation and, later, for the test set.

4.3 Input size 288 x 224 (height x width)

  • Measured on the dataset: median aspect ratio (W/H) = 0.784 and median equivalent side median(sqrt(W*H)) is about 259 px, giving a target of 229 x 292 (W x H).
  • Rounded to multiples of 32 (ResNet18 reduces spatial size by a factor of 32): 224 x 288 (W x H), aspect ratio 0.778. In code this is IMAGE_SIZE = (288, 224) as (height, width).
  • Alternatives rejected: 128 x 128 would discard about three quarters of the pixels of a typical image; a square frame would stretch the typical (0.784) image by about 28%.
  • The same size is used for all models, so the baseline and the ResNet comparison differ only in architecture and pretraining.
  • Note for implementers: torchvision expects (height, width) while Pillow expects (width, height). The conversion happens explicitly where Pillow is called.

4.4 Letterbox resizing (aspect-preserving resize + padding)

  • LetterboxResize uses ImageOps.pad (bicubic, centered). No cropping, because many images are tight crops where the vehicle fills the frame.
  • Padding colour is the dataset mean colour, (117, 119, 122), so padding is about 0 after normalization and neutral for the network.
  • Existing white borders in some images are left untouched (white ambulances make automatic trimming risky).
  • Trade-off: very wide images leave a large part of the frame empty. For example, a 357 x 241 image (ratio 1.48) becomes 224 x 151 content inside a 288-pixel-high frame, so about 48% of the frame is padding.

4.5 Normalization from the training split

  • Per-channel mean/std are computed on the training split only, on image content only (after the aspect-preserving resize, before padding). This avoids a circular dependency, because the padding colour is derived from the mean.
  • Computation: single pass, float64 accumulators, pixel-count weighting, std = sqrt(E[x^2] - E[x]^2), scale 0-1.
  • Result: mean [0.457, 0.4675, 0.4781], std [0.2596, 0.2522, 0.2492].
  • Cached in data/train_norm_stats.json together with an MD5 fingerprint of the train file list and the image size. The cache is recomputed if the split changes, the size changes, or the file is corrupted.
  • The ImageNet statistics will be used for the pretrained ResNet, because its weights expect them.

4.6 Augmentation (train only, off by default for the baseline)

Applied after the letterbox, on the fixed-size canvas, with the padding colour as fill value.

TransformParametersReason
RandomHorizontalFlipp = 0\.5travel direction should not define the class
RandomAffinedegrees = 10, translate = \(0\.08, 0\.08\), scale = \(0\.8, 1\.2\), bilinear, fill = padding coloursmall rotation, shift and zoom \(in and out\) in one resampling step
ColorJitterbrightness 0\.25, contrast 0\.25, saturation 0\.15, hue 0\.03lighting and camera variation; hue kept very small \(about \+/\- 11 degrees\)

Excluded on purpose:

  • RandomGrayscale: taxi colour (yellow/green) is the key cue.
  • RandomVerticalFlip: upside-down vehicles do not occur.
  • RandomResizedCrop: replaced by RandomAffine. After the letterbox it can only zoom in (cutting parts of tightly cropped vehicles) and adds a second resampling.
  • GaussianBlur: deferred; most images are sharp.

4.7 DataLoaders and reproducibility

  • batch_size = 32 (divisible by the 8 classes, so a balanced batch will hold 4 images per class).
  • Train: shuffle=True with a dedicated torch.Generator seeded from the run seed. Validation: no shuffling, so metrics are comparable and predictions map back to val_loader.dataset.paths[i].
  • set_seed seeds Python random, NumPy and torch (CPU and CUDA) and sets cuDNN to deterministic mode (benchmark off). seed_worker seeds NumPy and random inside each worker process.
  • get_dataloaders returns only train and validation loaders. The test loader will be built separately at the final evaluation, so the test set cannot be touched by accident during experiments.
  • num_workers = 4 for real training runs and 0 for quick debug runs (see 6.2).

7. Leakage and reproducibility controls

RiskControl
Near\-duplicate images across train and validationgroup\-aware split from Goal 1; validate\_split asserts no shared path or group\_id
Statistics leaking validation/test informationmean/std computed from the train split only, cache invalidated by a fingerprint of the train files
Augmentation changing evaluationaugmentation exists only in the train transform; the eval transform is deterministic
Accidental use of the test setno test loader is created in this module
Silent label errorsfixed class list, unknown classes raise ValueError, visual label check
Non\-repeatable runsglobal seed, dedicated shuffle generator, worker seeding, deterministic cuDNN; verified by the same\-seed test

Reproducibility is guaranteed for the same seed on the same machine and software versions; very small numerical differences are possible on other GPUs or library versions.

8. Known limitations and risks

  • hue = 0.03 is the only augmentation that touches colour. If taxi recall drops in later experiments, set it to 0 first.
  • The letterbox keeps shape but wastes frame area on very wide or very tall images. A stretch-vs-letterbox comparison is possible as an optional experiment (it would need a resize-mode option, not implemented).
  • The augmentation strength is a starting point and will be treated as an ablation hyperparameter; the exact values must be stored in each run's configuration (the transform repr already prints them).
  • set_seed currently lives in data.py; it will move to a shared module when the package imports are finalised with train.py.
  • The ImageNet mean/std constants for the ResNet runs are not yet defined.
